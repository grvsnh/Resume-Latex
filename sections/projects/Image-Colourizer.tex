\begin{cvproject}{\href{https://github.com/grvsnh/Image-Colorization}{Image Colorization using Deep Learning} | Python, TensorFlow, OpenCV, Streamlit}{}
    \item Developed a dual-model image colorization system combining a custom CNN trained on the Oxford-IIIT dataset with a pretrained ECCV 2016 colorization model for realistic grayscale-to-RGB reconstruction.
    \item Implemented an end-to-end LAB color space pipeline to predict chrominance (AB) channels, reconstruct RGB images, and compare outputs from custom and pretrained models.
    \item Built an interactive Streamlit application with automatic model downloading, caching, and side-by-side result visualization for efficient deployment and evaluation.
\end{cvproject}
